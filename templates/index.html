// about

From legacy code
to learning machines

I started out building a student portal for my college library, in PHP and Laravel, as an intern figuring out how production software actually gets made. Since then, I've spent four years migrating legacy systems — VB applications that businesses depended on but couldn't safely touch — into modern ASP.NET Core and Angular stacks, across three enterprise projects from architecture to deployment.

Along the way I've designed RESTful APIs with Entity Framework, improved application performance by roughly 25% through better architecture and database handling, and worked in Agile teams that consistently hit on-time delivery.

I'm currently based in Berlin, pursuing an M.Sc. in Artificial Intelligence, focused on machine learning, NLP, computer vision, and robotics. My goal isn't to leave software engineering behind — it's to bring the same rigor I've applied to legacy systems to building dependable, intelligent products.
